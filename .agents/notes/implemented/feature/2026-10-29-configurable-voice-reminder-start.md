# Agent Note: Configurable voice action hint timing

Status: implemented

## Problem

真机验收位置、文字气泡和固定回退时，每次等待50秒效率低。用户要求紧凑单行，并能设置提示出现时间，保留默认临近提醒。

## Decision

用户后续要求倒计时全段常驻，只在临近时限展开“松开再按”。保留schema6的持久化键`voiceLimitReminderStartSeconds`及0–55整数范围，当前语义改为真实ATVV START后多少秒展开操作提示，默认50；0立即展开。UI直接标注“展开操作提示”，原步进器、5秒测试和恢复默认继续可用，已有设置值保留，不清空映射、设备或能力开关。倒计时本身不再受该值门禁。

时间值只控制尾部展开，不能重置真实单调起点。5秒测试表示第5秒显示“松开再按”，仍按60秒估计倒计时，最后5秒图标变红；60秒只表示估算上限，不伪造硬件结束。常驻短胶囊104×34pt，提示出现时0.24秒展开至164pt；系统减少动态效果时直接切换。定位覆盖真实段，预览与空闲仍不扫描。

schema1–5读取时缺省为50，schema6的既有整数保留；越界值仍拒绝加载，便携配置保留时间但继续关闭能力。5秒无设备预览固定从约剩12秒开始，第2秒按默认阈值展开，结束后恢复仍在进行的真实段，不重新开麦、不修改保存的时间。新检查范围见[记录](../../../../docs/validation/2026-11-07-persistent-voice-countdown.md)。

## Alternatives considered

- 只改测试时钟：不能验收真实事件与微信位置，保留实际操作提示阈值与快速测试入口。
- 暂时改硬编码再改回：无法让用户自主配置，且需要反复编译与重新关联权限。
- 快速测试自动复位：隐藏的复位时机会干扰连续验收，采用可见的恢复默认按钮。
- 沿用schema5悄悄增加字段：旧应用保存时可能丢失新选择；schema6让旧版保留原数据并明确拒绝未来配置。

## Consequences

用户随后明确授权0.2.13公开推送与保留设置的远端源码升级，实际交付过程单独记录。新的全段显示会增加语音段内窗口复核时长；操作提示阈值不再控制这项开销，空闲仍不查询。移植、检查与真机边界见[记录](../../../../docs/validation/2026-10-29-compact-reminder-timing.md)。跨屏按用户当前仅单屏的条件跳过；第一轮用户报告右侧，但采集仅录到空闲，不能作为50秒和松开隐藏通过证据。
